# 数据库

在「设置 → 数据库」里维护多个数据源，模型就能直接查它们，而不是让你复制粘贴结果。

## 支持

海量 Vastbase / openGauss、达梦 DM8、PostgreSQL、MySQL、SQLite。

海量默认 `sha256` 认证，原版 `pg` 连不上；这里用 `opengauss.js`
（基于 node-postgres 8.22 与官方 `openGauss-connector-nodejs`），支持 sha256 与 SM3。

## 配置

每条数据源填名称、方言、主机、端口、库名、用户名、密码和模式。可以就地「测试连接」，
不用先保存。密码存在 DSH 凭据库，不写进配置文件，也不会回传到界面。

## 安全边界

- 只读数据源：语句白名单 + 数据库会话只读 + 界面开关，三层都拦。
- 可写数据源：每条语句弹出审批，理由里带完整 SQL；一次授权只管一条。
- 模型只能看到数据源名称和地址，看不到密码。

## 限制

单次返回行数有上限；结果以文本表格给模型；Oracle / SQL Server 暂未支持。
